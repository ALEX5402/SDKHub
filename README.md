# SDKHub

A premium, high-performance web interface and API portal for Android NDK, SDK platform packages, build-tools, system emulator images, and CMake releases. Powered by Next.js 15, Tailwind CSS, and a local Turso (LibSQL/SQLite) database store.

## Features

- **IDE-Style UI**: Beautiful dark space-cyber design styled with JetBrains Mono (JetBrains Nerd Font).
- **Console Dashboard**: Interactive hero terminal, dynamic category filters, custom outline badges, and detailed metrics.
- **Deduplicated Indices**: Automatically fetches, deduplicates, and caches metadata for thousands of packages from 22 distinct Google repository feeds.
- **Redirect CDNs**: Performs programmatic redirects to fetch zip archives directly from raw Google CDN servers.
- **Developer REST APIs**: CORS-enabled endpoints to query categories, unique versions, and downloads directly from CLI pipelines.
